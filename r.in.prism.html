DESCRIPTION

r.in.prism downloads PRISM gridded climate data from Oregon State University's PRISM Climate Group and imports raster maps into GRASS GIS.

Two dataset types are supported via the mode option:

mode=timeseries (default)
Downloads monthly or daily gridded data for a requested date range. Each time step is imported as a separate raster map named <output>_YYYYMM (monthly) or <output>_YYYYMMDD (daily).
mode=normals
Downloads PRISM 30-year normals (1991–2020 base period) for selected months. Maps are named <output>_01 through <output>_12. Use months= to import a subset of months.

No authentication is required. All data are fetched directly from NOAA/OSU servers over HTTPS. PRISM data cover the conterminous United States (CONUS) only.

Each downloaded GeoTiff is automatically reprojected and clipped to the current GRASS computational region via r.import.

NOTES

Projection and resolution

PRISM data are distributed in NAD83 geographic coordinates (EPSG:4269) at approximately 4 km (0.0417°) resolution, 1405 × 621 pixels, covering CONUS. r.in.prism uses r.import to reproject and clip to the current region in a single step; the region CRS is not restricted.

Variables

CodeDescriptionUnits
pptTotal precipitationmm
tminMinimum temperature°C
tmaxMaximum temperature°C
tmeanMean temperature°C
tdmeanMean dew point temperature°C
vpdminMinimum vapour pressure deficithPa
vpdmaxMaximum vapour pressure deficithPa

Units are as distributed by PRISM; no conversion is applied.

Space-time raster datasets

Use the -t flag to register imported maps as a GRASS space-time raster dataset (strds). The strds is named output. For monthly maps, each map's temporal extent covers the full calendar month. For normals, a synthetic reference year of 2020 is used.

Data availability

  • Timeseries data are available from 1895-01 (monthly) or 1981-01-01 (daily) through near-present.
  • Very recent dates (last 1–2 months) may return 404 if provisional data are not yet published. Missing dates are skipped with a warning.
  • Normals are based on the 1991–2020 base period.

EXAMPLES

Import monthly precipitation from 2000–2020: 
r.in.prism output=ppt_monthly variable=ppt start=2000-01 end=2020-12
Import and register as a space-time raster dataset: 
r.in.prism output=ppt_monthly variable=ppt start=2000-01 end=2020-12 -t
Import daily Tmax for a single month: 
r.in.prism output=tmax_daily variable=tmax frequency=daily start=2015-07-01 end=2015-07-31
Import 30-year normal precipitation for all months: 
r.in.prism output=ppt_normal variable=ppt mode=normals
Import 30-year normal temperatures for winter months only: 
r.in.prism output=tmin_winter variable=tmin mode=normals months=12,1,2
